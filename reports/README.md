# reports/

Generated by the pipeline. Rerunning `make pipeline` rewrites them.

| File | What's in it |
|---|---|
| `phase1/PHASE1_AUDIT.md` | Data audit: what one record means, data quality, berth matching |
| `phase1/data_quality.md` | Profile of every raw CSV |
| `leakage_check.md` | Every model input, and why it's known at prediction time |
| `turnaround_comparison_<segment>.md` | Turnaround at arrival: Random Forest, HistGradientBoosting and GradientBoosting vs medians |
| `E10_final_test_<segment>.md` | Final test report: errors by ship type, checkpoint and port; ports never seen in training |
| `E11_simulation_<segment>.md` | Speed simulation: waiting, fuel, CO₂ and money vs sailing at normal speed (simulated) |
| `figures/` | Charts used in the reports and the website |

`<segment>` is `liner` (container and cruise, the headline) or `other` (tanker, bulk, general cargo). A summary is in [docs/results.md](../docs/results.md).
